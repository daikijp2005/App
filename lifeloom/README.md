# Lifeloom

Life と Loom（織機）を組み合わせた名前です。「明日」「数ヶ月」「数年」の3つの時間を、1枚の布のように織り合わせて見るカレンダーアプリです。

`index.html` をブラウザで開けば動きます（ビルド不要）。データはブラウザの localStorage に保存されます。

| 画面 | 時間の幅 | 中身 |
|---|---|---|
| **Dawn**（あしたの設計図） | 1日 | 外出時間・帰宅時間から、起床〜就寝までを横向きのタイムラインに組み立てる。フライヤー風のデザインで、画像として保存できる。記録の一覧、時間のルールの設定、前日21:00のリマインドつき |
| **Season**（数ヶ月の航路） | 1〜6ヶ月 | 中期計画を「今日・今週」「計画カレンダー」「目標ボード」の3つの見せ方で表示。大目標・タスク・締切（自分の締切と公式の締切）・期間ブロックとルール・手順の逆算・ペース目標・まとめて延長・候補の比較・カウンター・週の振り返り・毎朝のリマインド |
| **Journey**（歳月の年表） | 数年 | 所属期間を横に長い帯グラフで表示。今日より前は実線、今日より後は斜線（予定・未確定）に自動で切り替わる。Season の計画も年表の上に表示される |

## 最初から入っているデータ
- Dawn：`log.md` の記録（10/22 デート、10/23 大学）
- Season：「2026年 残り3ヶ月の計画（10/1〜12/31）」（5つの大目標、集中期間、締切、タスク、延長・変更の記録など）
- Journey：「大学生活の所属期間（2024年4月〜2028年3月）」の年表

「⋯」メニューから、JSON の書き出し・読み込みと、初期データへのリセットができます。
