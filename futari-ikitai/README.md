# あれどこ

**行きたい場所、もう忘れない。**

「あれ、どこ行きたいって言ってたっけ？」——誰もが一度は言ったことのある一言を、そのままアプリの名前にしました。
SNSで見つけた「ここ行きたい！」を、恋人・友達・家族・職場の仲間などと貯めておき、うろ覚えでも見つけられるアプリです。

## ほかのアプリとの違い

| | よくある保存・地図アプリ | あれどこ |
| --- | --- | --- |
| 探し方 | 店名やキーワードを覚えていないと探せない | **うろ覚え検索**：「海が見えるカフェ」「先月はるかが見つけた安いとこ」で見つかる。AIに文章で聞くこともできる |
| 保存 | 自分のブックマークにばらばらに残る | 一緒に行く人と1つのリストに。リンクを貼るだけでジャンル・場所・値段・営業時間まで読み取る |
| 決め方 | 「どこ行く？」のやりとりがチャットで流れていく | スワイプで**投票・答え合わせ**、全員（または過半数）が行きたい場所は**マッチ** |
| 出かけ方 | 自分でルートを組む | 行きたい場所から**プランを自動作成**して、地図・カレンダー・LINEへワンタップ |
| その後 | 行ったら終わり | ★と感想で**足あと**に。都道府県マップで振り返れる |

## 誰とでも使える

リストを作るときに「誰と使うか」を選びます（あとから設定で変えられます）。選んだ相手に合わせて、言葉づかいやタブの名前が変わります。

| 相手 | 「行きたい」が揃ったとき | プランのタブ |
| --- | --- | --- |
| 💑 恋人 | ふたりとも行きたい | デート |
| 🙌 友達 / 🏠 家族 / 💼 職場 / 🎈 知人・サークル | みんな／過半数が行きたい（例: 3/5人） | おでかけ・プラン |
| 🙋 ひとりで | （投票なし。自分用メモ） | プラン |

- 1つのリストに最大50人まで参加できます。2人までは全員、3人以上は過半数（最低2人）が「行きたい」と答えるとマッチです。
- 恋人用・友達用・家族用など、リストをいくつでも作って、上のリスト名から切り替えられます。
- 初めて開いたときは、使い方をスライドで紹介します（設定の「使い方を見る」からいつでも見られます）。

同じ画面を2つの形で使えます。

| | Webアプリ版（このフォルダ） | アーティファクト版（claude.ai） |
| --- | --- | --- |
| 一緒に使う人に必要なもの | **招待リンクだけ（名前を入れるだけ。登録・サインイン不要）** | claude.ai のアカウントとサインイン |
| 置き場所 | 自分でサーバーに置く（下の「公開する」） | claude.ai 上で動く |
| リンクの自動読み取り | リンク先を開いて読む | 開けないので、本文やスクショを読む |
| 写真・地図表示 | あり | なし（外部の画像・地図を読み込めないため） |
| AI読み取り | サーバーにAPIキーを入れると自動 | 「AIで読み取る」を押した人のClaudeで |

## できること

**集める**
- リンクを貼るだけで、Instagram / TikTok / X / YouTube / Threads / Lemon8 / 食べログ / Googleマップなどから、ジャンル・店名・住所・駅・値段・営業時間・定休日・ハッシュタグを読み取ります。
- 読み取れない投稿は、本文を貼るかスクリーンショットを選べば読み取れます。
- Androidでは各SNSの「共有」から直接送れます（ホーム画面に追加したとき）。
- 同じ投稿を二重に登録しようとすると教えてくれます。

**みんなで決める**
- **答え合わせ・投票**: ほかの人が見つけた場所を、カードを左右にスワイプして「行きたい／うーん」で答えます。必要な人数が「行きたい」と答えると**マッチ**します。
- **プランを自動で作る**（恋人ならデートコース）: 行く日・出発する時間・回る数・予算を選ぶと、みんなの「行きたい」から近い場所どうしを組み合わせます。ランチは昼に、バーは夜に置き、移動手段と時間割を付けます。営業時間外になりそうな場所も警告します。そのまま予定に入れたり、Googleマップのルートや LINE で相談に回せます。
- **迷ったらガチャ**: 移動時間・予算・みんなの♡・いま営業中で絞ってランダムに決めます。

**メンバーを楽しむ**
- **メンバー図鑑**: 上のアイコンを押すと開きます。メンバーごとに、見つけた場所や投票から自動で付く**称号**（発見王👑・甘党代表🍰・こだわり審査員🧐・おしゃべり隊長💬 など）、見つけた数・♡の数・行けた数、よく見つけるジャンル、**あなたとの相性％**（投票が一致した割合）を表示します。3人以上なら**ベストコンビ**も発表します。
- 相手の名前をニックネームに変えられます（全員に反映）。
- 自分のアイコンを、絵文字か写真（自動で小さく切り抜き）に変えられます。

**カレンダー**
- プランのタブにある月のカレンダーに、予定（ジャンルの絵文字）・期間限定の締め切り・行った日が並びます。
- 日付を押すと、その日の予定・締め切り・思い出を一覧し、「この日に予定を入れる」で行きたい場所から選んで（時間も指定して）予定にできます。その日の分をまとめてルート表示・LINE共有もできます。
- 「これからの予定」（今日・明日・あと◯日）と、日にち未定の予定も表示します。

**自分好みに**
- メインカラーを8色（ローズ・サンセット・マスタード・ミント・オーシャン・ブルー・ラベンダー・チャコール）から選ぶか、好きな色を指定できます（端末ごと）。ダークモードでは見やすい明るさに自動で調整します。

**逃さない**
- **いまのおすすめ**: 期間限定の締め切りが近い場所、今が旬の場所（桜・紅葉・イルミネーション・かき氷など）、いま営業中で近い場所をホームに並べます。
- 営業時間と定休日から「営業中／まもなく閉店／今日は定休日」を判定します。

**すぐ出かける（外部アプリをワンタップで）**
- 元の投稿、電車の経路、車のナビ、Googleマップ、Appleマップ、食べログ、予約探し、Instagramでほかの投稿を見る、Googleカレンダー、iPhoneカレンダー（.ics）、LINEで送る、コピー。スマホではそれぞれのアプリが開きます。

**残す**
- **足あと**: 行った場所を都道府県タイルマップ、ジャンル別のグラフ、月ごとの思い出（★評価と感想）にまとめます。
- スポットごとのコメント、メモ、ピン留め。

**うろ覚えで探す**
- 検索欄に、覚えているままの言葉を入れて探せます（例:「海が見えるカフェ」「甘いやつ」「近くて安いとこ」「先月見つけたちょっといい店」「はるかが見つけた焼肉」）。
- 「海→ビーチ・海辺・オーシャン」のような言いかえ辞書と、「安い・近い・最近・期間限定・行った・〇〇が見つけた」などの条件を読み取り、どう読んだかを表示します。行った場所も探せます。
- AIが使えるとき（アーティファクト版、またはサーバーにAPIキーを設定したWebアプリ版）は、「AIに聞く」で文章のまま質問できます。

**整理する**
- ジャンルは色分けされ、ホームの色つきボタンでジャンルをワンタップで絞り込めます。
- 追加日・ジャンル・エリア・移動時間・予算・見つけた人・**共有元（Instagram・TikTokなど）**でグループ分けします。
- 検索、絞り込み（ジャンル・エリア・予算・移動時間・見つけた人・いま営業中）、並べ替え（新しい順・近い順・安い順・♡順・期限順）ができます。
- 登録した出発地（家・職場・よく集まる駅など）からの徒歩・電車・車の目安時間を表示します。

## 使い方（Webアプリ版）

1. 初めて開くと使い方のスライドが出ます。続けて「誰と使いますか？」で相手を選び、リスト名と自分の名前を入れて作ります
2. 招待画面の「LINEで送る」（またはほかのアプリ・コピー）で、一緒に使う人にリンクを送ります
3. 招待された人はリンクを開き、名前を入れて「参加する」を押すだけで使えます
4. 設定で出発地を登録します（駅名・住所・GoogleマップのURL・現在地）
5. 行きたい投稿のリンクを上の欄に貼ります
6. 別の相手と使うリストは、上のリスト名 →「新しいリストを作る」から作れます

招待リンクを知っている人は誰でもリストを見て参加できます。使う人以外には教えないでください。

## 公開する（相手がサインインなしで使えるようにする）

みんなのスマホから使うには、インターネット上のサーバーに置きます。データはファイルに保存するので、**消えない保存場所（ディスク）を必ず付けてください**。PWA（ホーム画面に追加・共有メニュー）には HTTPS が必要ですが、下のサービスなら最初から HTTPS です。

**Render（いちばん簡単）**
1. このリポジトリを GitHub に置いた状態で、Render の「New → Blueprint」からリポジトリを選ぶ
2. リポジトリ直下の `render.yaml` が読まれ、サーバーと1GBのディスクが作られる（ディスクは有料プランで使えます）
3. AIで読み取りたいときは `ANTHROPIC_API_KEY` を入れる（空でも動きます）
4. 発行されたURLを開いてリストを作り、一緒に使う人に招待リンクを送る

**そのほか**
同梱の `Dockerfile` で、Railway や Fly.io など Docker が動くサービスに置けます。どこに置く場合も、ディスク（ボリューム）を `/data` に付けてください。

## 手元で動かす

Node.js 20 以上が必要です。

```bash
cd futari-ikitai
npm install
npm start          # http://localhost:3000
npm test           # 解析・営業時間・プラン作り・うろ覚え検索のテスト
```

| 環境変数 | 説明 |
| --- | --- |
| `PORT` | ポート番号（既定 3000） |
| `DATA_DIR` | データ保存先（既定 `./data`） |
| `ANTHROPIC_API_KEY` | 設定するとAIで読み取る（スクリーンショットの読み取りと「AIに聞く」も有効） |
| `ANTHROPIC_MODEL` | AI読み取りに使うモデル（既定 `claude-opus-5-5`） |
| `GEOCODER_UA` | 住所→緯度経度の変換（OpenStreetMap Nominatim）に送る User-Agent |

## しくみ

```
public/
  core.js        画面のすべて（Webアプリとアーティファクトで共通）
  smart.js       誰と使うか・マッチの人数・うろ覚え検索・営業時間・旬・プラン作り・外部アプリのリンク（画面に依存しない）
  util.js        移動時間・値段などの計算
  main.js        Webアプリ版の入り口（リストの作成・参加・切り替え・サーバーとの同期）
  style.css      共通のスタイル
lib/
  analyze.js     本文 → ジャンル・場所・値段・営業時間（ブラウザとも共有）
  preview.js     リンク → oEmbed / OGP / JSON-LD の取得
  ai.js          （任意）Claude による読み取り
  geo.js         住所・店名 → 緯度経度
artifact/
  backend.js     アーティファクト版の入り口（claude.ai の共有データとClaudeを使う）
  build.mjs      1ファイルのHTMLに組み立てる: node artifact/build.mjs
server.js        APIサーバー（Node標準の http のみ）＋ SSE でリアルタイム同期
```

画面（`core.js`）は、データの読み書きを `backend` オブジェクトに任せています。`main.js` と `artifact/backend.js` が同じ形の backend を用意します。具体的には `subscribe` / `addSpot` / `updateSpot` / `deleteSpot` / `vote` / `comment` / `saveSettings` / `readPost` / `locate` / `people` / `me` と、できることを表す `features` です。

### 注意点

- Instagram はログインしないと中身を返さないことが多いので、読み取れないときは本文を貼るかスクリーンショットを使ってください。
- 移動時間とデートコースの時間は直線距離から出した目安です。正確な時間は「経路」から Googleマップで確認できます。
- SNSの画像URLは時間が経つと切れるので、登録時にサーバーへ画像を保存しています。
