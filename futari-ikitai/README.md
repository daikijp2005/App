# 💞 ふたりの行きたいリスト

SNSで見つけた「ここ行きたい！」を、恋人とふたりで貯めておくWebアプリ（PWA）です。
**「あれ、どこ行きたいって言ってたっけ？」をなくす**のが目的です。

## できること

| 機能 | 内容 |
| --- | --- |
| 🔗 URLを貼るだけで自動読み取り | Instagram / TikTok / X / YouTube / Threads / Lemon8 / 食べログ / Googleマップ / 一般のWebページの URL から、タイトル・画像・本文を取得し、**ジャンル・場所（店名/住所/最寄り駅）・値段・営業時間・ハッシュタグ**を推定 |
| 📝 キャプション貼り付け解析 | ログインが必要で読み取れない投稿は、本文をコピーして貼れば同じように解析 |
| 🤖 AI解析（任意） | サーバーに `ANTHROPIC_API_KEY` を設定すると、Claude で読み取り精度が上がる（未設定ならルールベースで動作） |
| 🚃 移動時間 | 登録した出発地（ふたりの家・職場・よく行く駅など複数OK）から、徒歩・電車・車の**目安時間**を表示。Googleマップの経路検索にワンタップで移動 |
| 🗂️ 見やすく分類 | **追加日・ジャンル・エリア・移動時間・予算・見つけた人**でグループ分け。検索、絞り込み（ジャンル/予算/移動時間/ふたりとも♡/追加した人）、並べ替え（新しい順・近い順・安い順・♡順・期限順） |
| 🗺️ マップ | 全スポットを地図にピン表示（ステータス別に色分け） |
| 💞 ふたりとも行きたい | 相手が追加したスポットにも♡。両方♡のスポットは「ふたりとも」マーク付き |
| 🔄 リアルタイム同期 | 相手が追加・更新すると、すぐ自分の画面にも反映されて通知 |
| ⏳ 期間限定の期限 | ポップアップや季節イベントの終了日を入れると、2週間前から上部でお知らせ |
| 📅 予定 → ✅ 思い出 | 「行きたい → 予定あり（日付）→ 行った（★評価・感想）」の流れで管理 |
| 💬 コメント | スポットごとにふたりでやりとり（「今度の土曜いこ！」など） |
| 🎲 どこ行く？ガチャ | 移動時間・予算・ジャンル・ふたりとも♡ で絞ってランダムに決定 → そのまま予定に |
| 👀 重複チェック | 同じ投稿を登録しようとすると「○○さんが登録済み」と教えてくれる |
| 📱 ホーム画面に追加 | PWA対応。Androidでは各SNSの「共有」から直接このアプリに送れる（Share Target） |
| 💾 バックアップ | リスト全体をJSONで書き出し |

## 使い方

1. トップページで「あなたの名前」と「恋人の名前」を入れてリストを作成
2. 表示された**招待リンク**を恋人にLINEなどで送る（相手は開いて「あなたはどっち？」で自分を選ぶだけ）
3. ⚙️設定 →「出発地」でふたりの家などを登録（住所・駅名で検索、または現在地）
4. 行きたい投稿のURLを上の欄に貼って「読み取る」→ 内容を確認・修正して追加

> 🔒 招待リンクを知っている人は誰でもリストを見られます。ふたり以外には共有しないでください。

## 起動方法

Node.js 20 以上が必要です。

```bash
cd futari-ikitai
npm install        # AI解析を使わないなら省略してもOK（依存パッケージなしで動きます）
npm start          # http://localhost:3000
```

| 環境変数 | 説明 |
| --- | --- |
| `PORT` | ポート番号（既定 3000） |
| `DATA_DIR` | データ保存先（既定 `./data`）。リストは `<部屋ID>.json`、画像は `images/` に保存 |
| `ANTHROPIC_API_KEY` | 設定するとAI解析が有効に |
| `ANTHROPIC_MODEL` | AI解析に使うモデル（既定 `claude-opus-5-5`） |
| `GEOCODER_UA` | 住所→緯度経度の変換（OpenStreetMap Nominatim）に送る User-Agent |

ふたりのスマホから使うには、Render / Railway / Fly.io などにデプロイしてください（**データが消えないよう永続ディスクを `DATA_DIR` に割り当て**てください）。PWAの「ホーム画面に追加」や共有メニュー連携には HTTPS が必要です。

## しくみ

```
public/          画面（素のHTML/CSS/JS、ビルド不要）
  app.js         画面のロジック
  util.js        移動時間・値段などの計算
  sw.js          PWA用 Service Worker
server.js        APIサーバー（Node標準の http のみ）＋ SSEでリアルタイム同期
lib/preview.js   URL → oEmbed / OGP / JSON-LD の取得
lib/analyze.js   テキスト → ジャンル・場所・値段・営業時間の推定（ルールベース）
lib/ai.js        （任意）Claude による抽出
lib/geo.js       住所・店名 → 緯度経度（Nominatim）
test/            解析ロジックのテスト（npm test）
```

### 注意点

- **Instagram はログインしないと中身を返さないことが多い**ため、読み取れなかった場合はキャプション貼り付けで解析してください。
- 移動時間は直線距離から計算した**目安**です。正確な時間は詳細画面の「電車の経路／車の経路」から Googleマップで確認できます。
- SNSの画像URLは時間が経つと切れるため、登録時にサーバーへ画像を保存しています。
